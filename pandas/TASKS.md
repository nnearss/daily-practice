# задачи по pandas

данные в `data/*.csv`. в файле решения положи ответ в переменную `result`: число, строку, `Series` или `DataFrame`. индекс можно оставить или сбросить, важны значения и порядок колонок. файл запускается из корня репозитория, так что путь к данным: `data/products.csv`.

**01. Сколько товаров.** Загрузи `products.csv` и посчитай, сколько в нём строк. Одно число.  
файл · *file*: `pandas/01.py`

**02. Средняя цена.** Средняя цена товара, округлённая до 2 знаков. Одно число.  
файл · *file*: `pandas/02.py`

**03. Товары для бега.** Товары категории «Бег». Колонки: `name, price`.  
файл · *file*: `pandas/03.py`

**04. Клиенты по городам.** Число клиентов в каждом городе. Колонки: `city, количество`. Подсказка: `value_counts()` или `groupby`.  
файл · *file*: `pandas/04.py`

**05. Заказы москвичей.** Сколько заказов сделали клиенты из Москвы? Одно число. Подсказка: `merge`.  
файл · *file*: `pandas/05.py`

**06. Сумма заказа.** Сумма каждого доставленного заказа (количество × цена). Колонки: `order_id, сумма`.  
файл · *file*: `pandas/06.py`

**07. Топ-3 категории.** Три категории с наибольшей выручкой (доставленные заказы), по убыванию. Колонки: `category, выручка`.  
файл · *file*: `pandas/07.py`

**08. Лучший месяц.** Месяц с максимальной выручкой (доставленные) в формате `2025-12`. Одна строка. Подсказка: `.dt.strftime` или `.dt.to_period`.  
файл · *file*: `pandas/08.py`

**09. Средний чек по городам.** Средний чек доставленного заказа в каждом городе клиента, округлённый до 2 знаков. Колонки: `city, средний чек`.  
файл · *file*: `pandas/09.py`

**10. Повторные покупки.** Какой процент покупателей (у кого есть доставленные заказы) сделал 2 и больше доставленных заказа? Округли до 1 знака. Одно число.  
файл · *file*: `pandas/10.py`

**11. Дни недели.** Число заказов по дням недели (0 — понедельник, 6 — воскресенье). Колонки: `день, количество`. Подсказка: `.dt.dayofweek`.  
файл · *file*: `pandas/11.py`

**12. Сводная таблица.** Выручка (доставленные) в разрезе категория × квартал: строки — категории, колонки — кварталы 1–4 по порядку, пропуски заполни 0. Подсказка: `pivot_table`.  
файл · *file*: `pandas/12.py`

**13. RFM.** Для каждого клиента с доставленными заказами: давность (дней от последнего доставленного заказа до 2026-01-01), число доставленных заказов и выручка. Колонки: `customer_id, давность, заказов, выручка`.  
файл · *file*: `pandas/13.py`

**14. Топ-10% клиентов.** Клиенты, чья выручка (доставленные) выше 90-го перцентиля. Колонки: `customer_id`. Подсказка: `.quantile(0.9)`.  
файл · *file*: `pandas/14.py`

**15. Накопленная выручка.** Выручка нарастающим итогом по месяцам (доставленные), по порядку месяцев. Колонки: `месяц, накопленная выручка`. Подсказка: `.cumsum()`.  
файл · *file*: `pandas/15.py`
